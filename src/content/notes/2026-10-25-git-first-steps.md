## 三個最常用的指令

```bash
git add .
git commit -m "新增首頁"
git push
```

## 每個指令在做什麼

1. `git add`：把修改放進「準備區」
2. `git commit`：把準備區的內容存成一個版本，並寫下說明
3. `git push`：把本機的版本上傳到 GitHub
